# Data Analysis

Write and review analytical SQL, pandas/Polars code and notebooks with reproducible, honest results.

`/analyze` turns a question into analytical SQL or pandas/Polars code against a described schema or local files. The **Data Analysis** skill covers correctness pitfalls, reproducibility and honest reporting. No queries are executed; results are never invented.

## Permissions and limits
Commands are scoped to `read_file`, `grep_search` and `glob_files`; agents run in `plan` mode. No hooks, scripts, MCP servers or network access. Outputs are proposals and drafts; nothing is claimed executed, verified or passing without evidence supplied by the user. Targets IDE 1.3.10, Agent 1.1.8 and CLI 1.1.10. Original content is MIT.
