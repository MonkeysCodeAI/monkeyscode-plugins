---
description: Review component accessibility with evidence and manual check guidance
argument-hint: "[component path]"
allowed-tools: read_file, grep_search, search_files
---
Review $ARGUMENTS and directly related styles/components. Check semantic elements, accessible names, keyboard interaction, focus visibility/order/restoration, error announcements, motion and alternatives for non-text content. Cite applicable WCAG 2.2 criteria where confident; distinguish static findings from checks needing rendered UI.

Return findings with path and line, user impact, severity, minimal remediation and a reproducible keyboard or assistive-technology check. Do not claim contrast measurements, screen-reader testing or WCAG conformance without actual evidence. This read-only command does not launch a browser or change files. Recommend manual checks for computed colors, zoom/reflow and announcements, and request separate approved remediation if desired.
