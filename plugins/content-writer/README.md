# Content Writer

Clear, honest product copy, landing pages, blog posts and release announcements in the brand voice.

`/copy` writes or rewrites interface and landing-page copy. `/blog` drafts a technical blog post or release announcement from repository evidence. The **Writing Style** skill defines clarity rules. Pairs with `seo-toolkit` for metadata and `design-studio` for layout.

## Permissions and limits
Commands are scoped to `read_file`, `grep_search` and `glob_files`; agents run in `plan` mode. No hooks, scripts, MCP servers or network access. Outputs are proposals and drafts; nothing is claimed executed, verified or passing without evidence supplied by the user. Targets IDE 1.3.10, Agent 1.1.8 and CLI 1.1.10. Original content is MIT.
