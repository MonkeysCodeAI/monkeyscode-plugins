# Accessibility

Draft 1.0.0 by MonkeysCode (MIT). Use `/a11y path/to/component` for a read-only WCAG-oriented review; select the manual Accessibility Review skill for remediation and testing advice.

The command reads/searches source only. It cannot measure rendered contrast or perform screen-reader/browser testing. Findings include evidence and manual verification steps, not certification of WCAG conformance. Remediation and test execution require separate normal approval.

Supports IDE 1.3.10 and Code Agent 1.1.8 only, pending app acceptance; CLI is not declared for this UI-oriented package. No hooks, MCP, executables, network integration, environment inputs or dependencies. A separately requested UI test may require host-approved browser tooling.

Original text and static SVG, no vendored standards or third-party code. Rights review, signing and publishing approval remain release gates.
