# Next.js Toolkit

Draft 1.0.0 by MonkeysCode (MIT). Use `/route app/account` for a read-only route design proposal. Select the manual Next.js Toolkit skill for App Router, RSC, authorization and caching guidance grounded in installed dependencies.

The command reads/searches files only, and returns proposed paths/code and verification steps. It neither scaffolds files nor runs a build. Implementation and networked checks require a separate approved task. Cache defaults vary by version; static advice is not proof of runtime behavior.

Supports IDE 1.3.10, Code Agent 1.1.8 and CLI 1.1.10, pending cross-app acceptance. No hooks, MCP, bundled executables, automatic network access, environment inputs or additional dependencies. Any requested build/test remains under host permissions.

Original text and static SVG, no vendored Next.js code or implied affiliation. Rights review, approval and signing remain release gates.
