# Browser Testing

Playwright end-to-end and visual regression test drafting with resilient locators and stable fixtures.

`/e2e` drafts Playwright tests for a user flow using the project's existing configuration. The **Playwright Testing** skill covers locators, fixtures, network mocking, visual and accessibility checks and CI sharding.

No browser is launched and no dependency is installed by this plugin. Drafts are labeled not executed. Rendered checks requested by `design-studio` or `seo-toolkit` can be expressed as these tests.

## Permissions and limits
Commands are scoped to `read_file`, `grep_search` and `glob_files`; agents run in `plan` mode. No hooks, scripts, MCP servers or network access. Outputs are proposals and drafts; nothing is claimed executed, verified or passing without evidence supplied by the user. Targets IDE 1.3.10, Agent 1.1.8 and CLI 1.1.10. Original content is MIT.
