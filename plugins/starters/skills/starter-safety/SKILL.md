---
name: Starter safety
description: Generate inert starter files only after destination approval
trigger: manual
priority: 60
---
Read a selected starter recipe and confirm an empty destination or explicit overwrite selection. Templates are inert Markdown, not executable installers. Write only approved files, preserve dirty content, and show dependency and network requirements before installation. Never run package lifecycles, containers, migrations or checkout flows automatically. Keep credentials in ignored environment files and secrets backend-only. Billing examples require test-mode keys and a manual checkout request; live payment, deployment and cloud provisioning are separate approval gates. Run tests only with permission and report actual outcomes. SplitIt and ShortLink video sources and redistribution rights are unverified; do not fabricate or ship those demos.
