# Teaching Mode

Draft 1.0.0 by MonkeysCode (MIT). Choose the `teaching` output style explicitly for concise goal/code/decision/verification explanations. Select the manual Practical Teaching skill for optional learning exercises grounded in actual code.

The style does not run code or grant permissions. Requested implementations remain complete; optional exercises are separate unless the learner asks for a scaffold. Test suggestions are distinguished from actual results. Approval and credential hygiene remain part of the workflow.

Supports IDE 1.3.10, Code Agent 1.1.8 and CLI 1.1.10, pending app acceptance. No hooks, MCP, executables, automatic network access, environment inputs or additional dependencies. User-requested edits/tests still require host authorization.

Original text and static SVG; no third-party educational material is bundled. Rights review, signing and publishing approval remain release gates.
